# Amazon Reviews Sentiment Analysis

## Project Overview

This project performs sentiment analysis on real Amazon customer reviews using Natural Language Processing (NLP). The system classifies customer reviews into Positive, Negative, and Neutral sentiments and generates visualizations to understand customer opinions and market trends.

---

## Features

- Real Amazon Reviews Dataset
- Sentiment Analysis using TextBlob
- Positive, Negative and Neutral Classification
- Sentiment Bar Chart
- Sentiment Pie Chart
- Word Cloud
- Public Opinion Analysis
- Trend Identification
- CSV Output Generation

---

## Technologies Used

- Python
- Pandas
- TextBlob
- Matplotlib
- WordCloud

---
