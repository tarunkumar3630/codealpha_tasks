# E-Commerce Sales Data Visualization

## Project Overview
This project analyzes e-commerce sales data using Python. It generates a dataset, performs exploratory data analysis (EDA), and creates various charts and a dashboard.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Dataset Generation
- Data Cleaning
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Profit by Category
- Payment Mode Distribution
- Sales vs Profit
- Correlation Heatmap
- Dashboard
