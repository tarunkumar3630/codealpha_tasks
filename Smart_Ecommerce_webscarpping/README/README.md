# Smart E-Commerce Web Scrapping Dashboard

## Project Overview
This project demonstrates the process of collecting, analyzing, and visualizing e-commerce book data. The data was scraped from the "Books to Scrape" website, cleaned using Python, and analyzed through Power BI to create an interactive dashboard.

## Objectives
- Collect book data through web scraping.
- Clean and preprocess the dataset.
- Analyze book prices and availability.
- Create an interactive Power BI dashboard for visualization.

## Technologies Used
- Python
- Pandas
- BeautifulSoup
- Requests
- Matplotlib
- Power BI
- Visual Studio Code

## How to Run

1. Clone the repository.
2. Install the required libraries:

```bash
pip install pandas matplotlib beautifulsoup4 requests
```

3. Run the analysis script:

```bash
python Python_code/analysis.py
```

4. Run the visualization script:

```bash
python Python_code/visualization.py
```

5. Open the Power BI file:

```
Dashboard/Smart_Ecommerce_WebScrapping_Dashboard.pbix
```
